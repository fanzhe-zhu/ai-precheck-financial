# The Approval Bottleneck

**Every AI tool in finance optimizes generation. No one optimizes approval.**

A product opportunity for AI assistant platforms in financial services, taken end-to-end with zero user access — four persona deep-dives → confidence-graded community evidence → two competitive scan rounds → an in-workflow prototype → a blind-injection capability eval. The thesis survived being corrected four times. Built throughout with a frontier AI assistant as research and execution partner.

**Eval headline:** 20/20 recall on both corpora (every v2 run) · strict precision 87–100% by run · one policy miss (0/3) repaired by ~150 words of explicit rules with 120/120 zero regression · limitations stated.
